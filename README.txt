Swift Exercises — Solutions

This folder contains separate Swift source files for each task in the supplied Swift Exercises PDF.
Structure:
- One folder per topic (Topics 2–12)
- Three separate .swift files per topic (Task 1, Task 2, Task 3)
- Each file is intended to be run independently in Swift Playgrounds or with the Swift compiler.

Notes:
- Topic 2 Task 3 uses Foundation's String(format:), so add `import Foundation` at the top if running that file standalone.
- Some intentionally invalid examples from the worksheet are shown as comments so each solution file compiles.
- The ARC and retain-cycle demonstrations depend on object lifetime; run them as standalone Swift programs/playgrounds.
